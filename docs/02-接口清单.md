# 02 · 接口清单（逆向结果）

来源：站点主包 `assets/index-Cll3wLFe.js` 中的 service 层定义（`[bundle]`），以及登录后
评审面板网络面板的实际调用（`[live]`）。前端基址 `baseURL = "/api/v1"`，超时 30s，订单类接口 360s，
`X-Trace-Id` 为链路追踪头。

统一响应信封：`{"code":0,"data":...,"msg":"ok"}`；鉴权 `Authorization: Bearer <token>`（localStorage `token`）。

## 六、ChatGPT 侧（本次逆向真正关心的部分）

| 方法 | 路径 | 出处 |
| --- | --- | --- |
| GET | `/api/auth/session` | `[script]` |

## 七、Stripe 侧（支付落地）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `https://checkout.stripe.com/c/pay/{cs_id}` | 取商户 `pk_live_...` |
| GET | `https://api.stripe.com/v1/payment_pages/{cs_id}/init` | 拿 `init_checksum` / `config_id` / 金额 / 支付方式 |
| POST | `https://api.stripe.com/v1/payment_pages/{cs_id}/confirm` | 提交卡，完成扣款 |

`confirm` 字段见 `impl/zovo/stripe_pay.py`。Stripe 会轮换辅助字段（`client_attribution_metadata`、
`guid/muid/sid`），缺字段时按 `error.param` 修正即可。
